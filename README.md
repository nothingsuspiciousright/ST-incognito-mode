# 👁️ ST Incognito Cards (Режим инкогнито для карточек персонажей в SillyTavern)

Лёгкое расширение для **SillyTavern**, созданное для любителей эстетичных скриншотов и полной конфиденциальности. 

Одним кликом расширение мгновенно погружает задний фон в глубокий чёрный цвет, скрывает имена персонажей и превращает все аватарки-карты в загадочные заблюренные силуэты.

---

## ✨ Основные возможности

* **👁️ Кнопка быстрой активации:** Аккуратный глазок (`👁️`), который встаёт на одну линию со стандартными кнопками фильтров и управления списком персонажей в правой панели.
* **🌫️ Глубокий блюр карточек:** Аватарки персонажей в меню выбора (а также в верхней ленте недавних чатов и в профиле) размываются в непроглядную дымку (`blur 22px`).
* **🕵️‍♂️ Сокрытие имён:** Имена персонажей, версии карточек и подписи под ними полностью скрываются (`display: none`), оставляя только чистую колоду.
* **🖤 Затемнение фона:** При включении режима вся фоновая картинка плавно уходит в абсолютный чёрный бархат (`#000000`).
* **💬 Опция для чата:** В меню настроек **Extensions -> Incognito Cards** можно включить дополнительную галочку, чтобы режим инкогнито распространялся **и на сам чат** (скрывая имена и размывая аватарки собеседников прямо в переписке для безупречных скриншотов).

---

## 📥 Установка (Installation)

1. Откройте **SillyTavern** -> вкладку **Extensions** (иконка кубиков сверху) -> **Install extension**.
2. Вставьте ссылку на репозиторий:
   ```text
 https://github.com/nothingsuspiciousright/ST-incognito-mode
 ```

# 🌐 English Description

**ST Incognito Cards** is a lightweight privacy and screenshot-mode extension for **SillyTavern**. 

With a single click on the eye icon (`👁️`), it blacks out the background, hides character names, and blurs character avatars into mysterious silhouettes.

---

## ✨ Features

* **👁️ Quick Toolbar Button:** Integrates seamlessly right next to the filter/sort icons in the right character panel.
* **🌫️ Heavy Card Blur:** Applies a strong Gaussian blur (`22px`) strictly clipped inside the  card borders, keeping the layout neat.
* **🕵️‍♂️ Name Hiding:** Completely conceals character names and card versions from the list.
* **🖤 Blackout Background:** Fades out custom background images into pure pitch black.
* **💬 Optional Chat Masking:** An optional toggle in the Extensions menu to apply the blur and name-hiding directly inside the active chat log.

---

## 📥 Installation

1. Open **SillyTavern** -> go to the **Extensions** tab -> click **Install extension**.
2. Paste the repository URL:
   ```text
  https://github.com/nothingsuspiciousright/ST-incognito-mode
   ```
3. Click **Install** and refresh the page!
```
